PROJECT 01 // COURSEWORK & RESEARCH REPORT (LATE 2024)

Sleep Stage & Apnea Event Analysis

Developed a multi-channel physiological classification pipeline on the PhysioNet DREAMT wearable biosensor dataset, incorporating blood volume pulse (BVP), heart rate (HR), electrodermal activity (EDA), skin temperature (TEMP), and tri-axial accelerometer channels.

Consolidated 25 Parquet files through missing-value imputation, signal standardization, and domain feature engineering. Evaluated an XGBoost classifier achieving 85% accuracy across four-class sleep stage classification alongside obstructive apnea event distribution analysis, with temporal sequence modeling explored via LSTM (86% accuracy).

PROJECT 02 // COURSEWORK & RESEARCH REPORT (LATE 2024)

Real-Time Sleep Stage Estimation

Implemented an end-to-end biosignal filtering and feature extraction workflow using BioSPPy, computing time-domain metrics, power spectral density (PSD), heart-rate variability (HRV) indices, and movement intensity from raw physiological streams.

Conducted systematic model comparison across Random Forest, Support Vector Machine (SVM), and neural network architectures with hyperparameter tuning, paired with an interactive Tkinter GUI for inspecting raw versus filtered waveforms and live sleep stage predictions.

ENGINEERING ETHOS // THE PONYTAIL PRINCIPLE

Tie Back the Noise. Keep the Line of Sight Clear.

The Ponytail Principle is a commitment to practical restraint: gather loose complexity, bind it cleanly out of the way, and keep your field of view unobstructed while working on hard problems.

Whether configuring a terminal environment in Arch Linux and Neovim, writing brain.zsh, or cleaning noisy physiological waveforms, tools should never compete for attention. Every component should justify its presence through utility, legibility, and precision.

OPERATING AXIOMS
  • 01. Prefer plain text, inspectable pipelines, and deterministic behavior.
  • 02. Strip ornamental complexity before optimizing execution.
  • 03. Report empirical results honestly—separate verified metrics from open questions.
