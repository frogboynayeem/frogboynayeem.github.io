brain.zsh

A context-aware terminal layer for Zsh. It detects your project type, builds context from git and the file tree, routes it to AI tools (opencode, claude, llm), and parses errors from Rust, Python, JS/TS, Go, and the shell.

  • State machine and event hooks, with every module lazy-loaded
  • Session management for zellij and tmux
  • Installable via curl or Homebrew

Known gaps: autonomous-mode fix templates, bundled plugins, and Docker/config error parsing are still in progress.
